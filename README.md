# Data Analyst Job Market Analysis 📊

## 📌 Project Overview
This project analyzes the current job market for Data Analysts. The goal is to extract insights from job postings to understand the most in-demand skills, top hiring locations, and salary trends. This helps aspiring data analysts align their learning with market demands.

## 🎯 Objectives
- Analyze the most frequently requested technical skills (SQL, Python, Excel, Power BI, etc.).
- Identify the top cities/countries hiring for Data Analyst roles.
- Analyze the correlation between experience level and salary.
- Build an interactive dashboard for easy visualization.

## 🛠️ Tech Stack
- **Data Collection:** Kaggle Dataset / JSearch API (RapidAPI)
- **Data Cleaning & Processing:** Python (Pandas, NumPy)
- **Data Visualization:** Power BI / Matplotlib / Seaborn
- **Version Control:** Git & GitHub

## 📂 Project Structure
- `data/` : Contains raw and cleaned datasets.
- `notebooks/` : Jupyter notebooks used for data cleaning and EDA.
- `dashboard/` : Power BI dashboard file (.pbix).
- `README.md` : Project documentation.

## 📈 Key Insights
- **Top Skills:** Engineering (306 mentions), Data Analyst (279), Data Science (203).
- **Top Tools:** Machine Learning, Python, SQL, Tableau, AWS.
- **Top Hiring Companies:** Meta (70), Netflix (33), Amazon (18), Google (16).

## 🚀 How to Run This Project
1. Clone the repository.
2. Open the Jupyter Notebook to view the data cleaning process.
3. Open the `.pbix` file in Power BI Desktop to interact with the dashboard.
